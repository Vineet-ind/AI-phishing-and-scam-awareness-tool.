AI Phishing and Scam Awareness Tool

About the Project

This project aims to help users recognize potential phishing attempts and online scams and improve their cybersecurity awareness.

Features

- Awareness of common phishing and online scams
- A simple web-based interface
- Educational information about online safety

Technologies Used

- Python
- HTML
- CSS
- JavaScript

How to Use

1. Download or clone the repository.
2. Follow the setup instructions for the Python application.
3. Run the application and open it in your browser.
